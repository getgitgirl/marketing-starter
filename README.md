# marketing starter

The files I'd push to GitHub first if you work in marketing. None of them are code. They're plain text files that any AI tool (Claude, ChatGPT, Cursor) can read, so you stop explaining your brand from scratch in every chat.

| File | What it's for |
|---|---|
| [brand-voice.md](brand-voice.md) | who you're talking to, how you sound, words you never use |
| [CLAUDE.md](CLAUDE.md) | rules Claude Code reads at the start of every session |
| [.claude/skills](.claude/skills) | skills: jobs you repeat, written once as plain steps that Claude picks up by itself |
| [hooks.md](hooks.md) | your best hooks with their views |
| [content/posts.csv](content/posts.csv) | a log of every post and how it did |
| [content/templates](content/templates) | your brief and report templates |

## How to use it

1. Click **Use this template** at the top of this page and make your own copy. Set it to **private**.
2. Fill in each file with your own details. The examples show you the shape, and every number in them is made up.
3. Point your AI tool at the repo, or open it in Claude Code, and ask it to read `brand-voice.md` first.

## Before you push anything

Never push API keys, passwords or `.env` files, and keep client data out.
