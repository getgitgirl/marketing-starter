# Voice note to reel script

1. Read `brand-voice.md` and `hooks.md` first.
2. Find the one point in the voice note worth making. If there are two, pick the stronger and save the other for another reel.
3. Write 3 hook options in the style of my best hooks in `hooks.md`.
4. Write the script: hook, the point, one example, one clear call to action. Keep it under 45 seconds spoken.
5. Keep my words where you can. Cut the ums, the repeats and the setup.
6. Give me the script plus a one-line caption. Don't post anything.
