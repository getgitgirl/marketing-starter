# Prompts that worked

## Reel script into a carousel
**For:** repurposing one script into a saveable post
**Prompt:**
> Turn this reel script into a 6-slide carousel. One idea per slide, a hook on slide 1, a save prompt on the last slide. Use my brand-voice.md.

**Best result:** link the post here

## Caption in my voice
**For:** first drafts of captions
**Prompt:**
> Write a caption for this post using brand-voice.md. Short paragraphs, one question at the end, no hashtags in the body.

## Repurpose a blog post
**For:** turning one blog post into five social posts
**Prompt:**
> Read this blog post and pull out five standalone ideas. Write each one as a short post with its own hook.
